Solution Summary

This solution is a .NET 8 Agentic Software Engineering prototype built around a URL Shortener application. It demonstrates a governed end-to-end SDLC workflow using specialized agents for requirement analysis, architecture, implementation planning, testing, validation, documentation, and release readiness.
A central Agentic Orchestrator manages workflow dependencies, parallel execution, synchronization, shared context, audit history, retries, fallback, rollback, safe-stop, dynamic replanning, policy guardrails, and human approval. The solution supports greenfield, brownfield, and ambiguous requirements and can run in deterministic mode or optionally use a local Ollama LLM for Requirement and Architecture analysis.
The deliverables folder also contains supporting documentation:
- Agentic_URL_Shortener_Testing_Guide.pdf — setup instructions, Swagger test scenarios, request/response examples, and testing for both LLM-disabled and LLM-enabled modes.
- Agentic_AI_Assessment_Guide.pdf — overview of the agentic solution and assessment concepts.
- ARCHITECTURE.md — architecture, workflow, dependency graph, and component responsibilities.
- FINAL_ENGINEERING_SUMMARY.md — implementation summary, design decisions, trade-offs, and limitations.
- LLM_MODE.md — instructions and explanation for enabling the local Ollama LLM integration.
- SCENARIOS.md — greenfield, brownfield, ambiguous, recovery, and governance scenarios.
- TESTING_STEPS.md — steps for testing and validating the solution.
- Agentic_UrlShortener_Bug_Fixes.pdf — issues encountered during development, fixes applied, and related engineering decisions.
Together, the source code and documentation demonstrate both the working prototype and the engineering reasoning, testing, governance, and limitations behind the solution.
